# Retention, Cohorts & Churn Analysis

*Developed by Ritu Raj Singh*

## Project Overview

This project analyzes user retention, cohort behavior, churn, and early user engagement across both sides of a marketplace.

The objective is to understand how users behave during their first week, how retention changes over time, where churn occurs, and which early behaviors are associated with stronger retention.

## Business Objectives

* Measure overall user retention and churn.
* Analyze weekly retention from Week 1 to Week 4.
* Build cohort-based retention analysis.
* Compare retention across marketplace sides.
* Identify differences between retained and churned users.
* Analyze week-one user behavior.
* Understand the relationship between early engagement and later retention.

## Data Preparation

The dataset was cleaned and prepared in *Microsoft Excel*.

The cleaning process included:

* Removing duplicate records.
* Handling missing values.
* Standardizing text fields.
* Converting dates and numeric fields into appropriate formats.
* Creating a cohort month field.
* Preparing the dataset for analysis and visualization.

## Analysis

Python was used for analytical processing and business analysis.

The analysis covered:

* User-level overview
* Marketplace-side analysis
* Weekly retention
* Cohort retention
* Churn analysis
* Week-one behavioral comparison
* Engagement analysis
* Activity depth
* Retention and churn relationships

## Tableau Dashboard

The final dashboard was developed in *Tableau* and presents:

* Total Users

* Churn Rate
* Week 1 Retention
* Weekly Retention Curve
* Cohort Retention
* Marketplace-side Retention

## Key Outcome

The project provides a structured view of user retention and churn by combining cohort analysis with early user behavior. It helps identify retention patterns across marketplace sides and highlights week-one behaviors that can be investigated further as potential retention signals.

## Conclusion

This project demonstrates an end-to-end data analytics workflow from Excel-based data cleaning to Python analysis and Tableau visualization. The resulting analysis provides a practical framework for understanding retention trends, churn behavior, cohort performance, and early user engagement.
